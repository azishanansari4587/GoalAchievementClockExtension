
# ⏰ Goal Achievement Clock Extension

A Chrome browser extension that turns your new tab page into a beautiful and motivating goal-tracking dashboard.

## 🧭 Project Overview

**GoalAchievementClockExtension** helps users track and stay motivated toward their goals by displaying a customizable dashboard on each new tab. It integrates a clock, goal prompts, and visual enhancements to help maintain focus and productivity.

## 📁 Project Structure

- `manifest.json` – Metadata and permissions required for the Chrome extension.
- `newtab.html` – The main HTML layout for the new tab customization.
- `script.js` – JavaScript logic to handle user interaction and goal tracking.
- `style.css` – Custom styles for the extension's user interface.
- `favicon.png` – Icon for the extension.
- `triangles-6000197_1280.png` – Background or decorative image asset.

## 🔧 Getting Started

To run the extension locally in your Chrome browser:

1. **Clone or Download** this repository:
   ```bash
   git clone https://github.com/azishanansari4587/GoalAchievementClockExtension.git
   ```
2. Load the Extension in Chrome:

   - Open Chrome and navigate to chrome://extensions/.

   - Enable "Developer mode" using the toggle in the top right corner.

   - Click on "Load unpacked" and select the directory containing the extracted files.​

3. Test the Extension:

   - Open a new tab in Chrome to see the customized page provided by the extension.​
